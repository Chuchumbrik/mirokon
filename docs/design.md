# Mirokon — дизайн-система

> Направление: **премиальный минимализм**, палитра **«синий / стекло»**, геометричная крупная типографика.
> Сообщение: премиальность/качество + надёжность/гарантия. Гео: Москва и МО.
> Источник истины для токенов. Живой пример — `public/design-preview.html`.

## 1. Цветовые токены

| Токен | HEX | Назначение |
|---|---|---|
| `--ink` | `#0F172A` | Основной текст и заголовки |
| `--primary` | `#1E40AF` | Бренд, глубокий синий |
| `--primary-700` | `#1D4ED8` | Hover/насыщенный |
| `--accent` | `#3B82F6` | CTA, акценты, иконки |
| `--ice` | `#EFF6FF` | Фон-тинт секций |
| `--muted` | `#64748B` | Вторичный текст |
| `--border` | `#E2E8F0` | Границы, разделители |
| `--surface` | `#FFFFFF` | Карточки, основной фон |

Правило: фон преимущественно белый/лёд, синий — точечно (CTA, акценты). Один акцент на экран.

## 2. Типографика

- **Заголовки:** Montserrat 700/800, плотный трекинг `-0.02em`, крупно.
- **Текст:** Inter 400/500.

| Уровень | Размер (desktop) | Шрифт / вес |
|---|---|---|
| display | 4.5rem / 1.05 | Montserrat 800 |
| h1 | 3rem / 1.1 | Montserrat 800 |
| h2 | 2.25rem / 1.15 | Montserrat 700 |
| h3 | 1.5rem / 1.25 | Montserrat 700 |
| body-lg | 1.25rem / 1.6 | Inter 400 |
| body | 1rem / 1.6 | Inter 400 |
| small | 0.875rem / 1.5 | Inter 500 |

## 3. Форма, тени, сетка

- **Радиусы:** `--r-sm 12px`, `--r-md 16px`, `--r-lg 24px`, `--r-full 9999px`.
- **Тени (мягкие, низкие — премиум):**
  - `--sh-sm 0 1px 2px rgba(15,23,42,.06)`
  - `--sh-md 0 8px 24px rgba(15,23,42,.08)`
  - `--sh-lg 0 24px 48px rgba(15,23,42,.10)`
- **Spacing-шкала (4px база):** 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96.
- **Контейнер:** max-width 1200px, боковые поля 24px.
- **Отступы секций:** 96px desktop / 56px mobile.
- **Брейкпоинты:** 320 / 768 / 1024 / 1440.

## 4. Компоненты (базовый набор)

- **Кнопки:** `primary` (заливка accent, белый текст), `secondary` (контур + ink), `ghost` (текст). Паддинг 16×28, радиус `--r-md`, состояния hover/focus/active/disabled.
- **Карточка:** surface, `--border` 1px, `--sh-md`, радиус `--r-lg`.
- **Trust-чип:** маленький pill с иконкой (Гарантия 5 лет, Договор, Монтаж за 1 день).
- **Поля ввода/селекты:** 1px border, focus-ring accent.
- **Glass-эффект:** полупрозрачный белый + `backdrop-filter: blur` — точечно (акцентные карточки/модалки).

## 5. Принципы
1. Много воздуха, один акцент на экран, сдержанность.
2. Синий — для действия, не для фона.
3. Никаких распродажных баннеров и крикливости.
4. Триггеры доверия рядом с CTA.
